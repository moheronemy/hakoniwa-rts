## 1. 怪獣のデータ

怪獣は地形の1種（`HlandMonster`）として、マスの上に置かれる。マスの値の中に種類と体力が入っている。
- 種類 = `(値 >> 4) & 31`（0〜31）
- 体力 = `値 & 15`（0〜15）

種類ごとに次の5つの値を持つ。

| 項目 | 意味 |
|---|---|
| 最低体力（BHP） | 出現時の体力の最低値 |
| 体力の幅（DHP） | 出現時の体力 = 最低体力 + 0〜(幅−1) の乱数 |
| 特殊能力 | 下の表の番号 |
| 経験値 | 倒したミサイル基地に入る経験値 |
| 死骸の値段 | 倒した島に入る資金（億円） |

### 特殊能力の番号

| 番号 | 能力 | 効果 |
|---|---|---|
| 0 | なし | |
| 1 | 足が速い | 1ターンに最大2歩動く |
| 2 | 足がとても速い | 移動済みの印が付かないので、マスの処理順によっては何歩でも動く（原作のコメントでも「最大何歩か不明」） |
| 3 | 奇数ターンに硬化 | 硬化中はミサイルが効かず、行動もしない |
| 4 | 偶数ターンに硬化 | 同上 |
| 5 | ミサイル迎撃 | 当たったミサイルを確率で無効にする（基本50%） |
| 6 | 怪獣を攻撃 | 周囲2マスにいる、自分より体力の少ない怪獣を攻撃する |
| 7 | 衝撃波 | 移動先の周囲6マスを焼き払う |
| 8 | ランダムなターンに硬化 | ターン番号から作った疑似乱数で、硬化するかを決める |
| 9 | アイスストーム | 移動先の周囲6マスを凍らせる |

## 3. 共通の仕組み

### 行動の順番（毎ターン、怪獣がいるマスごと）
1. すでに動いた怪獣は飛ばす。
2. 固有の効果（13番の資金・食料など）。
3. **硬化中なら、そのターンは何もしない。**
4. 種類ごとの固有の攻撃（砲撃、隕石、他の怪獣への攻撃など）。
5. **移動**：隣の6マスからランダムに方向を選ぶ（最大3回試す）。入れないマスは、海・浅瀬・海の施設・山・油田・記念碑・大きな都市・他の怪獣など。入れるマスが見つからなければ動かない。
   - 移動先にあった施設は壊れ、元の場所は荒地になる。
6. 移動後の効果：分裂、召喚、衝撃波、アイスストームなど。
7. 移動先が**防衛施設**なら、防衛施設が自爆して広域被害を起こす（設定で切り替えられる）。**地雷**なら、地雷の威力が体力以上で怪獣は死ぬ。

### ミサイルとの関係
- ミサイルが当たると体力が1減る。0になると倒れて荒地になる。
  - 撃った島に死骸の値段の資金が入り、撃った基地に経験値が入る。
- 硬化中の怪獣にはミサイルが効かない。
- 迎撃の能力（5番）を持つ怪獣は、基本50%（`$HmonsterDefence = 500`／1000）でミサイルを無効にする。
  - 一部の上位の怪獣は、種類ごとに60〜100%の確率を個別に持つ（2章の表）。
  - 撃たれる側の島の状態（`co4`・`co99` という値。何を表すかは未確認）によって、無効になる確率が下がる。

### 自然に現れる条件
- 毎ターン、`乱数(0〜9999) < 1 × 島の面積（陸地のマス数）` で出現する。つまり**1ターンあたり「面積÷10,000」の確率**で、陸地150マスなら1.5%。
- ただし人口50万人以上の島に限る。
- 島の人口によって、出てくる種類の範囲が広がる。

| 島の人口 | 出てくる番号 |
|---|---|
| 50万人以上 | 1〜4 |
| 75万人以上 | 1〜8 |
| 90万人以上 | 1〜12 |
| 100万人以上 | 1〜23 |

### 他の島への派遣（命令「動物派遣」）
- 費用は1万億円。電力が足りないと実行できない。
- 自分の島と相手の島の両方が、人口5万人以上である必要がある。
- 島どうしの特定の状態（`etc7` という値。詳細は未解読）になっている相手にしか送れない。
- 送る怪獣の番号（0〜30）を指定する。相手の島では、次の「島全体の処理」で出現する。

### 自分の島に置く（命令「怪獣の購入・配置」「テトラの購入・配置」）
- 費用はそれぞれ3,980億円と1万億円。ペット型の怪獣（28〜30番）を自分の島で育てる仕組みと推定。

## 4. このゲームに取り入れる候補（メモ）

- 「体力・能力・経験値・死骸の値段」という構造は、仕様書8章の怪獣のパラメータにそのまま使える。
- 硬化（決まったターンに無敵）、迎撃、速さ、分裂、召喚、衝撃波、凍結、他の怪獣を襲う、島の資源を奪う、といった能力の種類は、ジャンルの要素として参考にできる。
- 人口に応じて出現の段階が上がる仕組みは、野生の怪獣（11章）に使える。
- ペットを育てる仕組みは、「怪獣使い型」AIや怪獣研究所の設計の参考になる。
