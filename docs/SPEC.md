# 仕様書（ドラフト v0.2）

島開発シミュレーションのしくみをもとにした、ブラウザで遊ぶ一人用のリアルタイムストラテジー。
プレイヤーは自分の島を1つ開発しながら、3つのAIの島と発展を競い、ミサイルや怪獣で攻撃し合う。

> 数値はすべて仮の値。調整は実際に遊びながら行う。
> 「未決事項」に挙げた項目は、決まり次第この文書に反映する。

---

## 0. 前提と方針

- **オリジナル作品として作る。** 島開発（埋め立て・農場・工場・基地・災害・怪獣）という
  ジャンルの共通要素は取り入れるが、既存作品の名称・キャラクター（怪獣名など）・画像・画面の見た目は使わない。
  既存作品のソースコードは移植せず、仕組みを参考にして一から設計・実装する。
- 一人用で、サーバーなしで動く（ブラウザだけで完結する）。
- 日本語UI。

## 1. ゲームの概要

| 項目 | 内容 |
|---|---|
| ジャンル | リアルタイムの島開発＋対戦ストラテジー |
| プレイ人数 | 1人（対AI 3島） |
| 1回のプレイ時間 | 数時間（セーブして続きから遊ぶ前提） |
| 操作 | マスを選んで建設や地形変更を命令するだけ（ユニットを直接操作しない） |
| マップ | 島ごとに 20×20 マス。自分の島1つと、AIの島3つ |
| 見た目 | 真上から見たドット絵（1マス32px程度）。最初は仮の絵で作る |

## 2. 時間

- **ゲーム中に一時停止の操作はない。** 時間は常に流れる。
- **タブを閉じたり裏に回したりすると止まる**（`document.hidden` を検知）。戻ると続きから進む。
  席を外している間にゲームが進むことはない。
  - タブを切り替えれば実質的に一時停止できてしまうが、これは**仕様として認める**。
- 換算（仮）：**現実の1秒＝ゲーム内の1日**、30日＝1か月、360日＝1年。
  - ゲーム内の1年はおよそ6分で、4時間遊ぶと約40年になる。
- シミュレーションは1日ごとの固定刻み（tick）で進む。ミサイルや怪獣の移動など、描画の動きは1日より細かく補間する。

### ターンの扱い

**このゲームにターンはない。** ターン制の島開発ゲームで「1ターンに1回」まとめて行う処理は、
すべてゲーム内の1日ごとに少しずつ進める。

| ターン制での処理 | このゲームでの扱い |
|---|---|
| 収入と食料の消費 | 毎日1日分ずつ増減する。画面では月ごとの収支としてまとめて見せる |
| 予約したコマンドを1ターンに1つ実行 | 命令を出すとすぐ着工し、決まった日数で完成する。同時に進められる数は建設隊の数まで（6章）。「1ターンに1手」という手数の制限は、「建設隊の数と工事日数」による制限に置き換わる |
| マスごとの成長と、単独のマスの災害 | 毎日判定する |
| 島全体の処理（人口・怪獣・広域災害・滅亡の判定） | 毎日判定する |
| ターンごとのログ | 日付（○年○月○日）付きのログ |
| ターンごとの表彰・ランキング | 月ごとや年ごとの集計（スコアの記録、年次の順位表示など） |
| 他の島への攻撃が、次のターン更新でまとめて処理される | 発射すると数日飛んでから着弾する。その間に迎撃できる（8章） |

**バランスを決めるときの換算**：ターン制のゲームの1ターンを、ゲーム内の**1か月（30日）**とみなす。
1ターンあたりの確率 p は、1日あたりの確率 `1 − (1 − p)^(1/30)` に換算する。
こうすると、1か月の間に起きる確率は元と同じになる。この換算はバランス調整の出発点として使うだけで、最終的な数値は遊びながら決める。

## 3. 勝利条件と敗北条件

ゲーム開始時に、次の3つから1つを選ぶ。

| モード | 勝利条件 |
|---|---|
| 制圧 | AIの島3つをすべて滅亡させる |
| 期限 | 期限（仮：30年・50年・80年から選ぶ）が来た時点でスコア1位 |
| 目標達成 | 決められた目標に、どの島よりも先に到達する（例：人口300万人、または巨大建造物の完成） |

- **滅亡**：島の人口が0のまま一定期間（仮：90日）続く、または陸地がなくなる。
- **敗北**：自分の島が滅亡する。期限モードでは、期限の時点で1位でなければ負け。
- **スコア**：人口・資金・技術・陸地の広さ・施設の数を重みを付けて合計する（式は後で決める）。

## 4. 資源と経済

| 資源 | 増やし方 | 使い道 |
|---|---|---|
| 資金 | 働いている人口からの税収、工場、資源の売却 | ほぼすべての建設と命令 |
| 食料 | 農場（陸）、養殖場（海） | 人口が毎日消費する。足りないと人口が減り、暴動が起きる |
| 人口 | 平地に住宅地ができ、育っていく | 働き手。農場・工場・油田などの仕事に就く |
| 電力 | 発電所（火力・太陽光・風力・原子力） | 工場・研究所・基地・迎撃施設が消費する |
| 石油 | 海上油田（浅瀬や海で探す） | 火力発電、高度な施設、ミサイル |
| 技術 | 研究所が研究ポイントを生む | 技術ツリーを解放する（7章） |

- **雇用**：仕事の数（施設の規模の合計）が人口より少ないと失業者が出る。失業率が高いと税収が減り、人口の伸びが止まる。
- **電力不足**：必要な電力に対する供給の割合だけ、電力を使う施設の効率が下がる。
  そのため相手の発電所を攻撃することに戦略的な意味が出る。
- 毎日の収支を計算し、ログと推移のグラフで見られるようにする。

## 5. マップと地形

- 島ごとに 20×20 マス。初期マップは乱数のシードから自動で作る。島の中央に陸地、外側に浅瀬と海を置く。
- 4つの島は別々のマップで、画面上部のタブで表示を切り替える。

### 地形と施設（初期案）

| 区分 | 種類 |
|---|---|
| 自然の地形 | 深い海、浅瀬、荒地、平地、森、山 |
| 住宅地 | 村 → 町 → 都市（人口の規模で見た目が変わる） |
| 生産 | 農場、養殖場、工場、海上油田 |
| 電力 | 火力発電所、太陽光発電所、風力発電所、原子力発電所 |
| 研究 | 研究所、怪獣研究所 |
| 軍事 | ミサイル基地、海底基地、迎撃施設、防壁 |
| その他 | 港、記念碑、巨大建造物（目標達成モード用） |

- 施設には規模（レベル）がある。同じ施設を重ねて建てると規模が上がる（例：農場1万人分→2万人分）。
- **軍事基地は、他の島からは森に見える**（9章）。

## 6. 命令（コマンド）

- マスを選ぶと、そのマスで実行できる命令がメニューに出る。
- 命令を出すと費用を**先に払い**、決まった日数をかけて完成する。
- 同時に進められる工事の数には上限がある（**建設隊**の数。最初は2つで、技術や施設で増える）。
  上限を超えた命令は待ち行列に入る。待ち行列は並べ替えと取り消しができる。

### 命令の初期案

| 区分 | 命令 |
|---|---|
| 地形 | 整地、埋め立て、掘削、植林、伐採、地ならし（山を崩す） |
| 建設 | 各種の施設を建てる、規模を上げる、撤去する |
| 探索 | 油田を探す（失敗することがある） |
| 攻撃 | ミサイル発射、怪獣派遣（8章） |
| その他 | 資源の売却、島の名前の変更 |

## 7. 技術ツリー

- 研究所が毎日研究ポイントを生み、プレイヤーが選んだ技術に使われる。
- 系統の初期案：
  - **土木**：工事が速くなる、建設隊が増える、大規模な埋め立て
  - **産業**：工場の効率が上がる、油田が改良される
  - **エネルギー**：太陽光 → 風力 → 原子力
  - **軍事**：ミサイルの種類、精度、迎撃
  - **生物**：怪獣研究所、怪獣の強化
  - **防災**：災害の被害を減らす、予報

## 8. 攻撃と防衛

### ミサイル
- ミサイル基地から、相手の島のマスを狙って発射する。
- **着弾にはばらつきがある**（基地の経験値や技術で狭くなる）。
- 着弾までの飛行時間は仮で3日。その間に相手の**迎撃施設**の範囲に入ると、一定の確率で撃ち落とされる。
- 種類の案：通常弾、精密弾、広域弾、地形破壊弾、核弾頭（技術で解放）。
- 基地は撃つほど経験値がたまり、精度と連射数が上がる。

### 怪獣の派遣
- 怪獣研究所で怪獣を育て（費用と日数がかかる）、相手の島に放つ。
- 放たれた怪獣は自動で動き回り、施設を壊す。ミサイルや防衛施設で倒せる。
- 怪獣はすべてオリジナルのデザインにする。種類と能力は別途決める。

### 防衛
- 迎撃施設（周囲のマスに飛んでくるミサイルを確率で撃ち落とす）、防壁（怪獣の進入を防ぐ）、基地による反撃。

## 9. 情報の公開

- 相手の島のマップと数値（人口・資金・食料など）は**すべて見える**。
- 例外として、軍事基地は森に偽装されて見えない。研究中の技術と、待ち行列にある命令も見えない。

## 10. AI

- AIの島は3つ固定。**それぞれ性格が違う**。
  - **軍事型**：基地を早くから建て、積極的にミサイルを撃つ
  - **内政型**：経済と技術を優先し、防衛を固めて後から逆転を狙う
  - **怪獣使い型**：怪獣研究所を中心に、怪獣を送り込む
- プレイヤーと同じルール（資源・工事の日数・建設隊の上限）で動く。ズルをしない。
- 判断は一定の間隔（仮：5〜10日ごと）で行い、優先度の高い命令を出す。
- 難易度の選択と組み合わせるかは未決（未決事項を参照）。

## 11. 災害と野生の怪獣

- 地震、津波、台風、隕石、噴火、火災、地盤沈下（陸地を広げすぎた場合）。
- 人口が増えると、野生の怪獣が現れることがある。
- 開始時に強さを「なし／弱い／ふつう」から選ぶ。全部の島に同じ確率で起きる。

## 12. セーブ

- 自動セーブ：一定間隔（仮：ゲーム内30日）ごとと、タブが裏に回ったとき。
- 保存先はブラウザの IndexedDB（容量の都合で localStorage は使わない）。
- 手動のセーブ枠をいくつか用意する。セーブデータはファイルに書き出して読み込めるようにする。
- セーブデータには形式のバージョン番号を付け、古い形式からの変換に対応する。

## 14. 技術構成

- Vite + React + TypeScript、テストは Vitest。
- **ゲームの中身はReactと分ける。** `step(state, rng) → state` という純粋なTypeScriptの関数で作り、
  乱数はシード付きにする。こうすると同じ入力から同じ結果が再現でき、テストしやすい。
- マップの描画は Canvas 2D（ドット絵を拡大しても荒れないよう、補間をオフにする）。UIの部分は React。
- AIも、ゲームの状態を読んで命令を返す純粋な関数として作る。

## 15. 開発の段階（案）

1. **M1**：雛形、ゲームの中身、自分の島だけ（地形・住宅地・農場・工場・資金・食料・人口）、セーブ
2. **M2**：電力・石油・技術ツリー
3. **M3**：AIの島3つ、ミサイル、迎撃
4. **M4**：怪獣（野生と派遣）、災害
5. **M5**：勝利条件、スコア、バランス調整、ドット絵の差し替え
