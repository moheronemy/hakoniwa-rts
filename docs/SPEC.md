# 仕様書（ドラフト v0.21）

島開発シミュレーションのしくみをもとにした、ブラウザで遊ぶ一人用の島開発ストラテジー。
プレイヤーは自分の島を1つ開発しながら、3つのAIの島と発展を競い、ミサイルや怪獣で攻撃し合う。

**ターン制だが、ターンは数秒ごとに自動で進み、プレイヤーを待たない。**
「6時間に1ターン」だったターン制の島開発ゲームを、「数秒に1ターン」に縮めたものと考える。

> 数値はすべて仮の値。調整は実際に遊びながら行う。
> 「未決事項」に挙げた項目は、決まり次第この文書に反映する。

---

## 0. 前提と方針

- **オリジナル作品として作る。** 島開発（埋め立て・農場・工場・基地・災害・怪獣）という
  ジャンルの共通要素は取り入れるが、既存作品の名称・キャラクター（怪獣名など）・画像・画面の見た目は使わない。
  既存作品のソースコードは移植せず、仕組みを参考にして一から設計・実装する。
- 一人用で、サーバーなしで動く（ブラウザだけで完結する）。
- 日本語UI。

## 1. ゲームの概要

| 項目 | 内容 |
|---|---|
| ジャンル | 自動で進むターン制の島開発＋対戦ストラテジー |
| プレイ人数 | 1人（対AI 3島） |
| 1回のプレイ時間 | 数時間（セーブして続きから遊ぶ前提） |
| 操作 | マスを選んで命令を予約するだけ（ユニットを直接操作しない） |
| マップ | 島ごとに 20×20 マス。自分の島1つと、AIの島3つ |
| 見た目 | 真上から見たドット絵（1マス32px程度）。最初は仮の絵で作る |

## 2. ターンと時間

### ターンの進み方
- **ターンは一定の間隔（初期値：5秒）で自動的に進む。** プレイヤーの入力を待たない。
  - 間隔は**ゲームの途中でもいつでも変えられる**（仮：3秒・5秒・10秒・20秒）。変えた間隔は次のターンから効く。
  - 4時間遊ぶと、5秒間隔なら約2,880ターンになる。
- 時間の表示は**ターン数だけ**にする。暦（○年○月）は表示しない。
- **ゲーム中に一時停止の操作はない。**
- **タブを閉じたり裏に回したりすると止まる**（`document.hidden` を検知）。次のターンまでの残り時間を保ったまま止まり、戻ると続きから進む。
  - タブを切り替えれば実質的に一時停止できてしまうが、これは**仕様として認める**。
- 画面には、ターン数と、次のターンまでの残り時間を表すゲージを常に表示する。

### 1ターンの処理順
すべての島（自分の島とAIの島3つ）について、毎ターン次の順で処理する。島を処理する順番は、ターンごとに乱数で決める。

1. **収入・消費**：税収、食料の生産と消費、電力の収支、石油の生産、研究ポイントの加算
2. **命令の実行**：各島の命令予約の先頭から、**1ターンに1つ**実行する（6章）
3. **マスごとの処理**：住宅地の成長、森の成長、単独のマスで起きる災害、怪獣の移動
4. **島全体の処理**：人口の増減、広域の災害、野生の怪獣の出現、食料不足、滅亡の判定
5. **集計**：ログ、スコア、順位の記録

ターンの処理そのものは一瞬で終わる。その後、次のターンまでの時間でミサイルの着弾や怪獣の移動などを演出として表示する。

### バランスの参考値
ターン制の島開発ゲームの「1ターンあたり」の数値（成長率・災害の確率など）は、換算せずにそのまま出発点として使える。
最終的な数値は遊びながら決める。

## 3. 勝利条件と敗北条件

勝ち方は**軍事的制覇**と**経済的制覇**の2つで、**両方が同時に有効**。どちらかを最初に達成した島が勝つ。
どの島も期限までに達成できなければ、**期限の時点でスコア1位**の島が勝つ。

| 勝ち方 | 条件 |
|---|---|
| 軍事的制覇 | 自分以外の島をすべて滅亡させる |
| 経済的制覇 | 決められた目標の数値に、どの島よりも先に到達する（標準45万人。開始時に30万・45万・60万人から選べる。23章） |
| 期限 | 期限（仮：1,000・2,000・3,000ターンから開始時に選ぶ）が来た時点でスコア1位 |

- AIの島も同じ条件で勝てる。**AIが先に制覇を達成したら、プレイヤーの負け。**
- **滅亡**：島の人口が0になる、または陸地がなくなる。
- **敗北**：自分の島が滅亡する／AIのどれかが制覇を達成する／期限の時点で1位でない。
- **AIは降伏しない。** 軍事的制覇には、すべてのAIの島を実際に滅亡させる必要がある。

### スコア
ターン制の島開発ゲームでよく使われる「総合ポイント」の考え方を参考に、島の状態を重みを付けて合計する（重みは仮）。

| 要素 | 重み（仮） |
|---|---|
| 人口（100人単位） | ×1 |
| 資金 | ÷100（大きな額になると伸びが鈍るようにする） |
| 食料 | ÷100 |
| 農場の規模 | ×2 |
| 工場の規模 | ×1〜2（種類による） |
| 陸地の面積（マス数） | ×5 |
| 森の木の数 | ÷15 |
| 研究所 | ×30 |
| 軍事基地 | 経験値に応じて加算 |
| 海上油田 | ×500 |
| 記念碑・巨大建造物 | 種類ごとに500〜2,000 |
| 電力の供給量 | 加算（式は後で決める） |

- 毎ターン計算して順位を出し、期限モードの判定と順位表示に使う。

## 4. 資源と経済

| 資源 | 増やし方 | 使い道 |
|---|---|---|
| 資金 | 働いている人口からの税収、工場、石油の売却 | ほぼすべての命令 |
| 食料 | 農場（陸）、養殖場（海） | 人口が毎ターン消費する。足りないと人口が減り、暴動が起きる |
| 人口 | 平地に住宅地ができ、育っていく | 働き手。農場・工場・油田などの仕事に就く |
| 電力 | 発電所（火力・太陽光・風力・原子力） | 工場・研究所・基地・迎撃施設が消費する |
| 石油 | 海上油田（浅瀬や海で探す） | 火力発電、高度な施設、ミサイル |
| 技術 | 研究所が研究ポイントを生む | 技術ツリーを解放する（7章） |

- **雇用**：仕事の数（施設の規模の合計）が人口より少ないと失業者が出る。失業率が高いと税収が減り、人口の伸びが止まる。
- **電力不足**：必要な電力に対する供給の割合だけ、電力を使う施設の効率が下がる。
  そのため相手の発電所を攻撃することに戦略的な意味が出る。
- 毎ターンの収支をログと推移のグラフで見られるようにする。

## 5. マップと地形

- 島ごとに 20×20 マス。初期マップは乱数のシードから自動で作る。島の中央に陸地、外側に浅瀬と海を置く。
- 4つの島は別々のマップで、画面上部のタブで表示を切り替える。

### 地形と施設（初期案）

| 区分 | 種類 |
|---|---|
| 自然の地形 | 深い海、浅瀬、荒地、平地、森、山 |
| 住宅地 | 村 → 町 → 都市（人口の規模で見た目が変わる） |
| 生産 | 農場、養殖場、工場、海上油田 |
| 電力 | 火力発電所、太陽光発電所、風力発電所、原子力発電所 |
| 研究 | 研究所、怪獣研究所 |
| 軍事 | ミサイル基地、海底基地、迎撃施設、防壁 |
| その他 | 港、記念碑、巨大建造物（スコアが大きく増える） |

- 施設には規模（レベル）がある。同じ施設に重ねて建てると規模が上がる（例：農場1万人分→2万人分）。
- **軍事基地は、他の島からは森に見える**（9章）。

## 6. 命令（コマンド）

### 命令予約
- 各島は**命令予約**（仮：40枠）を持つ。プレイヤーはいつでも予約の追加・挿入・削除・並べ替えができる。
- 毎ターン、予約の**先頭から1つ**を実行する。**1ターンに実行される命令は原則1つ。**
- 予約の操作は、マップでマスを選ぶ → 命令を選ぶ → 予約の何番目に入れるかを選ぶ、の順で行う。
  同じ命令を複数ターン分まとめて入れる「数量」の指定もできる。
- 命令の費用は、**実行するときに**支払う。

### ターンを消費しない場合
次の場合はそのターンの手番を使わず、続けて予約の次の命令に進む。

- **実行できなかった命令**（資金不足、対象のマスが条件に合わない、など）。理由をログに残し、予約から取り除く。
- **即時命令**：費用が高い代わりにターンを消費しない命令。**当面は「地ならし」だけ**とする。
  - 地ならし：整地と同じ効果（荒地などを平地にする）だが、費用が整地よりずっと高い（仮：整地の数十倍）。
  - 1ターンに何回でも実行でき、その後に通常の命令が1つ実行される。

### 自動入力
予約を手早く埋めるための操作。それ自体は命令ではなく、予約に命令をまとめて入れるだけ（費用もかからない）。

- **整地自動入力**：島のすべての荒地に「整地」を予約する。
- **地ならし自動入力**：島のすべての荒地に「地ならし」を予約する。
- 荒地は島の上から順に入れる。すでに整地か地ならしを予約している荒地は飛ばす。
- 入れる位置は、命令を1つ追加するときと同じ（予約で選んでいる命令の前、選んでいなければ最後）。
- 既存の予約は消さず、空き枠の分だけ入れる。入りきらなかった数は画面に表示する。
- ほかの自動入力（浅瀬の埋め立て、伐採など）は、必要になったら追加を検討する。

### 予約が空のとき
- 予約が空なら、そのターンは「何もしない」になり、少額の資金が入る。

### 命令の初期案

| 区分 | 命令 |
|---|---|
| 地形 | 整地、地ならし（即時）、埋め立て、掘削、植林、伐採、山を崩す |
| 建設 | 各種の施設を建てる、規模を上げる、撤去する |
| 探索 | 油田を探す（失敗することがある） |
| 攻撃 | ミサイル発射、怪獣派遣（8章） |
| その他 | 何もしない（資金を得る）、石油の売却、島の名前の変更 |

## 7. 技術ツリー

- 研究所が毎ターン研究ポイントを生み、プレイヤーが選んだ技術に使われる。研究する技術の選択は命令予約とは別に行い、ターンを消費しない。
- 系統の初期案：
  - **土木**：埋め立ての費用が下がる、大規模な埋め立て、即時命令の追加
  - **産業**：工場の効率が上がる、油田が改良される
  - **エネルギー**：太陽光 → 風力 → 原子力
  - **軍事**：ミサイルの種類、精度、迎撃
  - **生物**：怪獣研究所、怪獣の強化
  - **防災**：災害の被害を減らす、予報

## 8. 攻撃と防衛

### ミサイル
- 「ミサイル発射」の命令で、相手の島のマスを狙って撃つ。1回の命令で、島にある基地の数を上限に複数発を撃てる（発数は命令で指定）。
- **着弾にはばらつきがある**（基地の経験値や技術で狭くなる）。
- 命令を実行したターンのうちに着弾まで処理する。相手の**迎撃施設**の範囲に落ちる弾は、一定の確率で撃ち落とされる。
- 種類の案：通常弾、精密弾、広域弾、地形破壊弾、核弾頭（技術で解放）。
- 基地は撃つほど経験値がたまり、精度が上がる。

### 怪獣の基本ルール
怪獣はすべてオリジナルのデザインにする（名前は別途決める）。原作の仕組みの調査は `docs/research/original-monsters.md` を参照。

- 怪獣はマスの上にいる。種類ごとに次の値を持つ。

| 項目 | 内容 |
|---|---|
| 体力 | 出現時は「最低体力＋0〜(幅−1)の乱数」。ミサイルが1発当たると1減り、0で倒れる |
| 特殊能力 | 下の「能力」から0〜2個 |
| 出現の段階 | 野生で現れる人口の段階（1〜4） |
| 経験値 | 倒したミサイル基地に入る |
| 死骸の値段 | 倒した島に入る資金 |

- **移動**：毎ターン、隣の6マスから方向をランダムに選ぶ（最大3回試す）。
  - 海・浅瀬・山・油田・記念碑・他の怪獣・防壁のマスには入れない。入れるマスがなければ動かない。
  - 移動先の施設は壊れ、元の場所は荒地になる。
  - 迎撃施設を踏むと、迎撃施設が自爆して周囲に被害を出す。
- **倒したとき**：倒れたマスは荒地になる。撃った島に死骸の値段の資金が、撃った基地に経験値が入る。
- **島にいられる怪獣の数**には上限がある（仮：7匹）。増殖の能力はこの上限までしか増えない。

### 能力

| 区分 | 能力 | 効果（数値は仮） |
|---|---|---|
| 基本 | 速さ | 1ターンに2歩動く |
| 基本 | 硬化 | 決まったターン（奇数／偶数／ランダム）に無敵になる。ミサイルが効かず、行動もしない |
| 基本 | ミサイル迎撃 | 当たったミサイルを確率（仮：50%）で無効にする。技術で確率を下げられる |
| 上位 | 増殖 | 移動するたびに、確率で元の場所に同じ種類が分裂する |
| 上位 | 範囲破壊 | 移動先の周囲6マスを焼き払って荒地にする（海・山は無事、油田は海に戻る） |
| 上位 | 資源への干渉 | 毎ターン確率で、島の資金か食料を一定の割合だけ奪う |

「他の怪獣を攻撃」「天変地異」「いるだけで資源をもたらす」は、今回は入れない（後で追加を検討する）。

### 怪獣の一覧（最初の8種・名前は未定）

| 仮番号 | 名前 | 段階 | 体力 | 能力 | 経験値 | 死骸の値段 | 役割 |
|---|---|---|---|---|---|---|---|
| M1 | （名前未定） | 1 | 1〜2 | なし | 5 | 400 | 最初に出会う弱い怪獣 |
| M2 | （名前未定） | 1 | 1〜2 | 硬化（奇数ターン） | 7 | 500 | 撃つターンを読むことを覚えさせる |
| M3 | （名前未定） | 2 | 2〜3 | 速さ | 15 | 800 | 動きが速く、被害が広がりやすい |
| M4 | （名前未定） | 2 | 3〜4 | ミサイル迎撃 | 12 | 1,000 | 多めに撃たないと倒せない |
| M5 | （名前未定） | 3 | 3 | 増殖 | 5 | 100 | 放っておくと島が埋まる。早く倒す必要がある |

- **野生での出現**：毎ターン「陸地のマス数 ÷ 10,000 × 災害の強さの補正（なし0・弱い0.5・ふつう1）」の確率で、島のどこかに1匹現れる。
  人口が一定の段階に達した島だけに現れ、段階が上がるほど強い種類が混ざる。各段階の人口は、経済のバランスを決めてから決める。
- この島は 20×20 マスで、原作の 12×12 マスより陸地が広くなりやすい。そのため出現の頻度は遊びながら調整する。

### 怪獣の派遣
- 「怪獣派遣」の命令で、怪獣研究所で育てた怪獣を相手の島に放つ（1ターンに1命令の手番を使う）。
- 派遣できる種類は、技術ツリー（生物の系統）で段階ごとに解放する。
- 費用は種類の強さに応じて決める。電力が必要。
- 放った怪獣は、相手の島で次のターンの「島全体の処理」で現れる。
- 自分の島や相手の島の人口が少ないうちは派遣できない（序盤の一方的な攻撃を防ぐため）。

### 防衛
- 迎撃施設（周囲のマスに飛んでくるミサイルを確率で撃ち落とす）、防壁（怪獣の進入を防ぐ）。

## 9. 情報の公開

- 相手の島のマップと数値（人口・資金・食料など）は**すべて見える**。
- 例外として、軍事基地は森に偽装されて見えない。研究中の技術と、命令予約の中身も見えない。

## 10. AI

- AIの島は3つ固定。**それぞれ性格が違う**。
  - **軍事型**：基地を早くから建て、積極的にミサイルを撃つ
  - **内政型**：経済と技術を優先し、防衛を固めて後から逆転を狙う
  - **怪獣使い型**：怪獣研究所を中心に、怪獣を送り込む
- **プレイヤーと同じルール**で動く。命令は1ターンに1つで、資源も同じように使う。ズルをしない。
- 毎ターン、状況を見て命令予約を組み直す。
- **難易度の選択は設けない。** AIどうしの違いは性格だけで、強さはどの性格も同じ水準に調整する。

## 11. 災害と野生の怪獣

- 地震、津波、台風、隕石、噴火、火災、地盤沈下（陸地を広げすぎた場合）。毎ターン確率で判定する。
- 人口が増えると、野生の怪獣が現れることがある（出現の条件は8章）。
- 開始時に強さを「なし／弱い／ふつう」から選ぶ。全部の島に同じ確率で起きる。

## 12. セーブ

- 自動セーブ：毎ターンと、タブが裏に回ったとき・閉じるとき（閉じる瞬間の保存は打ち切られることがあるため、毎ターンの保存を主にする）。
- 保存先はブラウザの IndexedDB（容量の都合で localStorage は使わない）。
- 手動のセーブ枠をいくつか用意する。セーブデータはファイルに書き出して読み込めるようにする。

## 16. M1 の具体的なルール（仮の数値）

数値はターン制の島開発ゲームでよく使われる値を出発点にしている。

### 単位
- 人口：内部では100人単位（表示は「○○○○人」）。
- 資金：億円。食料：100トン単位。
- 農場・工場の規模：1,000人単位（例：規模10＝1万人分の仕事）。森：100本単位。

### 地形と施設

| 地形 | 値の意味 | 備考 |
|---|---|---|
| 深い海 | － | |
| 浅瀬 | － | |
| 荒地 | － | 整地で平地にする |
| 平地 | － | 隣に住宅地か農場があると、1/5の確率で村になる |
| 森 | 木の数 | 毎ターン1（100本）ずつ増え、最大200 |
| 山 | － | 怪獣も入れない。M1では使い道なし |

### 命令（M1）

| 命令 | 費用 | 対象 | 効果 |
|---|---|---|---|
| 整地 | 5 | 荒地・森・住宅地・農場・工場 | 平地にする |
| 地ならし（即時） | 100 | 同上 | 整地と同じ。ターンを消費しない |
| 埋め立て | 150 | 浅瀬・深い海（隣に陸地が必要） | 深い海→浅瀬、浅瀬→荒地 |
| 掘削 | 200 | 陸地（山以外） | 浅瀬にする |
| 植林 | 50 | 平地 | 森（木の数1）にする |
| 伐採 | 0 | 森 | 平地にし、木の数×5億円を得る |
| 農場整備 | 20 | 平地・住宅地・農場 | 農場にする、または規模を上げる |
| 工場建設 | 100 | 平地・住宅地・工場 | 工場にする、または規模を上げる |
| 誘致活動 | 500 | － | そのターンだけ人口の伸びが大きくなり、都市も伸びる |
| 資金繰り | 0 | － | 10億円を得る（予約が空のときも自動でこれになる） |

### 1ターンの処理（M1）
1. **収入**：農場で働く人数＝min(人口, 農場の規模の合計×10)。その人数ぶん食料が増える。
   残りの人口のうち、工場の規模の合計×10 までの人数が工場で働き、10人単位（1,000人）につき1億円が入る。
2. **食料の消費**：人口×0.2。
3. **命令の実行**：予約の先頭から1つ（地ならしと、実行できなかった命令はターンを消費しない）。
4. **成長**：
   - 住宅地は、村・町なら毎ターン1〜10（誘致活動のターンは1〜30）増え、最大100。
     都市（100以上）は誘致活動のターンだけ1〜3増え、最大200。
   - 平地は、隣に住宅地か農場があれば1/5の確率で村（人口1）になる。森は1ずつ育つ。
5. **食料不足**：食料が0未満になったら0に戻す。住宅地はそのターン1〜30減り（0になると平地に戻る）、
   農場と工場はそれぞれ1/4の確率で暴動により荒地になる。

- 森を4か所、村を2か所、山を1か所、農場を1か所に置く（農場は M3 で追加。23章を参照）。

## 17. M2 の具体的なルール（仮の数値）

M2 では電力・石油・技術ツリーを加える。数値はすべて仮。

### 電力
- 単位は「万kW」。毎ターン、島全体の**供給**（発電所の出力の合計）と**需要**（消費の合計）を計算する。
- **供給率** = min(1, 供給 ÷ 需要)。需要が0なら1。
- 電力が足りないと、電力を使う施設の効率が供給率の分だけ下がる。

| 消費するもの | 消費量 | 足りないときの影響 |
|---|---|---|
| 工場 | 規模1（1,000人分）につき1 | 工場の収入 × 供給率 |
| 研究所 | 1棟（規模1段階）につき20 | 研究ポイント × 供給率 |
| 都市（人口1万人以上の住宅地） | 人口1万人につき5 | 供給率が1未満なら、都市は伸びない |

- M1 では工場は電力なしで動いていたが、M2 からは工場にも電力が要る。最初の工場の前に発電所を建てる流れになる。

### 発電所
建てる場所に条件がある。同じ発電所に重ねて建てると出力が上がる（段階）。

| 発電所 | 費用 | 建てられる場所 | 出力（1段階あたり） | 最大段階 | その他 |
|---|---|---|---|---|---|
| 風力 | 100 | 平地（隣に平地か荒地が2マス以上） | 10 | 3 | |
| 水力 | 300 | 平地（隣に山がある） | 50 | 3 | |
| 火力 | 1,000 | 平地（隣に海か浅瀬がある） | 100 | 5 | 1段階につき毎ターン石油1を使う。石油が足りない分だけ出力が下がる |
| 原子力 | 10,000 | 平地（隣に海か浅瀬がある） | 1,000 | 2 | 研究で解放。M3 以降、攻撃で壊れると周囲に大きな被害 |

### 石油
- **油田探し**（命令、費用300）：深い海のマスに使う。仮に**15%**の確率で海上油田が見つかる。外れると費用だけかかる。
- **海上油田**：見つかったときに埋蔵量（仮：200〜600）が決まる。毎ターン石油を5産出し、その分埋蔵量が減る。0になると枯れて海に戻る。
- **石油の売却**（命令、費用0）：持っている石油をすべて売る（1につき仮に3億円）。
- 石油の使い道：火力発電の燃料、M3 のミサイル、売却。

### 研究
- **研究所**（命令「研究所建設」、費用500）：平地に建てる。重ねると段階が上がる（最大3）。1段階につき毎ターン研究ポイント5（× 供給率）。
- **研究投資**（命令、費用1,000億円、1ターン消費）：研究ポイントを50得る。
- 研究する技術は、技術ツリーの画面からいつでも選び直せる（ターンを消費しない）。
  - 研究ポイントは、選んでいる技術に注ぎ込まれる。必要なポイントに達したら完成する。
  - 何も選んでいないときは、ポイントは貯めておき、選んだときに使う。
  - 途中で選び直しても、それまで注いだポイントは技術ごとに残る。

### 技術ツリー（M2・11個）
各系統の中では、上から順に研究する（前の技術が必要）。

| 系統 | 技術 | 必要ポイント | 効果 |
|---|---|---|---|
| 土木 | 埋め立て改良 | 300 | 埋め立ての費用 150 → 100 |
| 土木 | 海洋土木 | 900 | 埋め立てで、深い海を一度に荒地にできる |
| 土木 | 都市計画 | 1,800 | 誘致活動がなくても、都市が毎ターン1〜2伸びる |
| 産業 | 工場の自動化 | 450 | 工場の収入 +20% |
| 産業 | 大規模農業 | 600 | 農場の最大規模 5万人 → 8万人 |
| 産業 | 石油探査 | 750 | 油田探しの成功率が2倍 |
| 産業 | 精製技術 | 1,200 | 石油の売値 +50%、火力発電の燃料 −25% |
| エネルギー | 改良風車 | 300 | 風力の出力 +50% |
| エネルギー | 高効率タービン | 900 | 水力と火力の出力 +25% |
| エネルギー | 送電網 | 1,500 | 電力の消費 −15% |
| エネルギー | 原子力 | 2,400 | 原子力発電所を建てられる |

- 軍事・生物・防災の系統は、M3・M4 で追加する。

### 画面
- 資源の表示に、電力（供給／需要と供給率）、石油、研究ポイントを加える。
- 技術ツリーの画面（系統ごとの一覧、研究中の技術と進み具合）。

### 実装で決めた細かい点
- 1ターンの処理順：電力（火力の燃料を使う）→ 収入 → 油田の産出 → 命令 → 研究 → 成長 → 食料不足。
  研究を命令の後にしているので、研究投資のポイントはそのターンのうちに研究に注がれる。
- 発電所と研究所は平地に建てる。
- マスを対象にしない命令（石油の売却など）は、予約に入れるときは条件を見ず、実行するときに確かめる。
  条件を満たさなければ、ターンを消費せず次の命令に進む。
- 石油が尽きて火力発電所の出力が落ちたターンにだけ、ログで知らせる。
- 版1（M1）のセーブデータは、石油0・研究なしとして読み込む。
  M1 で建てた工場は、発電所を建てるまで収入を生まなくなる。
- 試しに自動で遊ばせると、研究所を次々に建てた場合、11個の技術は約250ターンですべて完成した。
  数時間遊ぶには少ないので、M3 以降で技術を増やすか、必要ポイントを上げる。

## 18. M3 の具体的なルール（仮の数値）

M3 では AI の島3つ・ミサイル・迎撃・勝敗を加える。数値はすべて仮。

### AI の島
- 自分の島と同じ方法で作る 20×20 の島を3つ置く。名前は仮に「北の島」「東の島」「南の島」。
- 性格は次の3つ。
  - **軍事型**：早くから基地と迎撃施設を建て、積極的にミサイルを撃つ。
  - **内政型**：経済と研究を優先する。迎撃施設で守りを固め、攻撃は後半に限る。
  - **バランス型**：内政と軍事を半々に行う（M4 で怪獣使い型になる）。
- **プレイヤーと同じルール**で動く。1ターンに1命令で、費用も研究も同じ。他の島の情報も、プレイヤーと同じ範囲しか使わない（基地は見えない）。
- AI どうしも敵どうしで、攻撃し合う。

### 基地
| 施設 | 費用 | 建てる場所 | 電力 | 他の島からの見え方 | 備考 |
|---|---|---|---|---|---|
| ミサイル基地 | 300 | 平地 | 5 | 森 | 最初から建てられる |
| 海底基地 | 3,000 | 深い海 | 10 | 深い海 | 研究「海底基地」が必要。直撃でしか壊れない |
| 迎撃施設 | 800 | 平地 | 10 | そのまま見える | 最初から建てられる |

- **基地のレベル**：基地は経験値を持ち、経験値でレベルが上がる。レベル＝1回の命令で1つの基地が撃てる発数。
  - ミサイル基地：経験値 0／20／60／120／200 でレベル 1〜5。
  - 海底基地：経験値 0／50／100／200 でレベル 1〜4。
  - 経験値は、撃った弾が相手の島の陸地に着弾すると+1、住宅地や施設を壊すと+3（最大255）。
- 電力が足りないと、1回に撃てる発数の合計が供給率の分だけ減る（最低1発）。迎撃の確率も供給率の分だけ下がる。

### ミサイル
- 命令「○○発射」で、**相手の島のマス**と**発数**（「撃てるだけ」も選べる）を指定する。1回の命令で1ターンを使う。
- 自分の基地を順に使い、各基地がレベルの数まで撃つ。指定の発数に達するか、資金・石油・基地の発数が尽きたら終わる。
- 1発ごとに資金と石油を使う。基地が1つもなければ実行できない（ターンは消費しない）。

| 弾 | 資金 | 石油 | 着弾のばらつき | 効果 | 解放 |
|---|---|---|---|---|---|
| 通常弾 | 20 | 1 | 狙ったマスの周囲2マス（19マス）のどこか | 着弾したマスを壊す | 最初から |
| 精密弾 | 100 | 2 | 周囲1マス（7マス）のどこか | 同上 | 研究「精密誘導」 |
| 高精度弾 | 500 | 3 | 狙ったマスちょうど | 同上。迎撃施設そのものを狙ったときは迎撃されない | 研究「ピンポイント誘導」 |
| 陸地破壊弾 | 1,000 | 10 | 周囲1マス | 着弾した陸地を浅瀬にする（山は荒地に、浅瀬は深い海に） | 研究「陸地破壊弾」 |
| 核弾頭 | 10,000 | 50 | 周囲1マス | 着弾点の周囲2マスを壊滅させる（周囲1マスの陸地は浅瀬に） | 研究「核弾頭」 |

**「壊す」の中身**（通常弾・精密弾・高精度弾）
- 住宅地・施設・平地・森は荒地になる（住宅地の人口は失われる）。
- 荒地・山・深い海・浅瀬に落ちた弾は効果がない。
- 海上油田と海底基地は、直撃すると壊れて深い海になる。
- 原子力発電所が壊れると、周囲2マスにも被害が広がる。

**迎撃**
- 迎撃施設の周囲2マス（19マス）に落ちる弾は、70%の確率で撃ち落とされる。迎撃施設がいくつ重なっても判定は1回。
- 研究「迎撃改良」で85%になる。

### 序盤の保護
- 開始から**100ターン**の間は、どの島もミサイルを撃てない（命令は実行できず、ターンは消費しない）。

### 軍事の技術（7個）
| 技術 | 必要ポイント | 前提 | 効果 |
|---|---|---|---|
| 精密誘導 | 600 | なし | 精密弾を撃てる |
| ピンポイント誘導 | 1,500 | 精密誘導 | 高精度弾を撃てる |
| 迎撃改良 | 900 | なし | 迎撃の確率 70% → 85% |
| 海底基地 | 1,200 | なし | 海底基地を建てられる |
| 陸地破壊弾 | 2,000 | 精密誘導 | 陸地破壊弾を撃てる |
| 核弾頭 | 4,000 | 陸地破壊弾 | 核弾頭を撃てる |
| 基地の自動化 | 1,000 | なし | ミサイル基地と海底基地の電力消費が半分 |

### 勝利と敗北（3章を M3 で実装する）
- 新しいゲームを始めるときに、**経済的制覇の目標人口**（30万・45万・60万人。標準45万人。23章で変更）と**期限**（仮：1,000・2,000・3,000ターン）を選ぶ。3つの勝ち方はすべて有効。
- **滅亡**：人口が0になるか、陸地がなくなった島は滅亡する。滅亡した島は命令を実行せず、攻撃の対象にもならない。
- **勝利**：軍事的制覇（自分以外がすべて滅亡）、経済的制覇（目標人口に最初に到達）、期限の時点でスコア1位。
- **敗北**：自分の島の滅亡、AI のどれかが制覇を達成、期限の時点で1位でない。
- 勝敗が決まったら時間を止め、結果の画面を出す。

### スコア（仮の式）
人口（100人単位）＋ 資金÷100 ＋ 食料÷100 ＋ 農場の規模×2 ＋ 工場の規模 ＋ 陸地の面積×5 ＋ 完成した技術×100 ＋ 発電の供給量。

### 情報と画面
- 画面上部の島タブで、自分の島と AI の島を切り替える。各タブに人口とスコアの順位を出す。
- AI の島のマップと数値は見える。ただし、ミサイル基地は森、海底基地は深い海に見える。研究中の技術と命令予約は見えない。
- AI の島を表示しているときにマスを選ぶと、命令メニューにミサイルの命令が出る（発数を選んで予約する）。
- ログには、自分の島の出来事、自分の島が関わる攻撃、島の滅亡を出す。AI の島の内部の出来事は出さない。
- 順位表（スコア・人口・面積）を出す。

### セーブ
- セーブデータの形式を版3にする。版2（M2）のセーブデータは、AI の島を新しく足して読み込む（その時点のターンから AI が始まる）。

### 実装で決めた細かい点
- **初期の島に農場を1つ置く**（1万人規模）。農場がないと、何もしないまま約37ターン（5秒間隔で約3分）で食料が尽き、
  人口0が続いて滅亡してしまうため。16章の「初期の島」もこれに合わせる。
- **滅亡の判定**：陸地がなくなったらすぐ、人口0が10ターン続いたら滅亡する（一時的に人口0になっても立て直せるように）。
- 軍事的制覇は、島が2つ以上あるゲームでだけ判定する。
- 1ターンの処理順：AI は自分の手番の最初に、その島の命令を1つ決めて予約する。島の順番はターンごとに乱数で決める。
  すべての島を処理したあとに、滅亡と勝敗を判定する。
- ミサイルの予約は序盤の保護の間もできる（実行するターンで判定し、保護中なら実行せず、ターンも消費しない）。
- ログには、自分の島の出来事、自分の島が関わる攻撃、島の滅亡と勝敗だけを残す。AI の島の内部の出来事は残さない。
- AI の性格はゲームごとに3つの島に割り振り直す。順位表には性格を表示する。
- AI の判断の優先順位：食料 → 火力発電の燃料（油田探し）→ 電力 → 攻撃 → 迎撃施設 → 基地 → 石油 → 研究所 → 工場 → 整地 → 埋め立て → 石油の売却 → 誘致活動。
  攻撃は性格ごとに決まった間隔で行い、軍事型はスコアの最も高い島を、ほかは最近攻撃してきた島（いなければスコアの最も高い島）を狙う。
  狙うマスは、見えている範囲で人口の多い住宅地（迎撃施設に守られたマスは避ける）。
- 試しに AI だけで800ターン進めると、各 AI は人口50万〜100万人ほどに育ち、AI どうしの攻撃は160ターン目ごろから始まった。
  800ターンでは滅亡する島は出なかった（攻撃の強さは M5 のバランス調整で見直す）。

## 19. M4 の具体的なルール（仮の数値）

M4 では怪獣（野生と派遣）、怪獣使い型の AI、防壁、災害を加える。数値はすべて仮。
怪獣の基本ルール・能力・8種の一覧は8章のとおり。

### 怪獣の名前
- 当面は仮の名前「怪獣M1」〜「怪獣M8」にする。名前は1か所（怪獣の定義）にまとめ、決まったら差し替える。

### マップ上の怪獣
- 怪獣は地形の1種「怪獣」としてマスに置く。マスの値に、種類と体力を入れる。
- 毎ターン「マスごとの処理」で動く（8章の移動のルール）。
  - 入れないマス：海・浅瀬・山・油田・海底基地・他の怪獣・**防壁**。
  - 移動先の施設は壊れ、元の場所は荒地になる。
- 能力の数値：
  - **速さ**：2歩動く。
  - **硬化**：奇数ターン・偶数ターン・ランダムのいずれか。硬化中はミサイルが効かず、動かない。
  - **ミサイル迎撃**：当たったミサイルを50%で無効にする。
  - **増殖**：移動するたびに30%で、元の場所に同じ種類が分裂する（体力は出現時と同じ）。
  - **範囲破壊**：移動先の周囲6マスの陸地を荒地にする。
  - **資源への干渉**：毎ターン20%の確率で、資金か食料の1/4を奪う。
- 島にいられる怪獣は7匹まで。増殖・出現・派遣もこの上限までしか増えない。
- **迎撃施設を踏むと**、迎撃施設が自爆して周囲1マスを荒地にする。怪獣も倒れる（死骸の値段はその島に入る）。

### 怪獣とミサイル
- ミサイルが怪獣に当たると体力が1減り、0で倒れる。倒れたマスは荒地になり、撃った島に死骸の値段の資金が、撃った基地に経験値が入る。
- **自分の島にもミサイルを撃てる**（怪獣を倒すため）。自分の島へは序盤の保護に関係なく撃てる。
  自分の島の施設に当たれば壊れるので、狙う場所に注意が要る。
- 陸地破壊弾・核弾頭が当たった怪獣は、体力に関係なく倒れる。

### 野生の怪獣
- 毎ターン「陸地のマス数 ÷ 10,000 × 災害の強さの補正」の確率で、島の陸地のどこかに1匹現れる（8章）。
- 島の人口で出る種類が変わる（段階）。

| 段階 | 島の人口 | 出る怪獣 |
|---|---|---|
| 1 | 30万人以上 | M1・M2 |
| 2 | 50万人以上 | M1〜M4 |
| 3 | 70万人以上 | M1〜M6 |
| 4 | 90万人以上 | M1〜M8 |

### 怪獣の派遣（研究所で育ててから送る）
- **怪獣研究所**（費用2,000、平地、電力20）：研究「怪獣研究」が必要。1棟につき1匹ずつ育てられる。
- **怪獣を育てる**（命令、怪獣研究所のマスに使う）：種類を選ぶ。費用は種類ごと。決まったターン数で育ち上がる。
  育てている間・育ち上がった怪獣は、他の島からは見えない。
- **怪獣派遣**（命令、目標の島を選ぶ）：育ち上がった怪獣を1匹送る。相手の島の陸地のランダムなマスに、そのターンのうちに現れる。
  序盤の保護（最初の100ターン）の間は送れない。

| 段階 | 怪獣 | 育てる費用 | 育つまでのターン数 | 必要な研究 |
|---|---|---|---|---|
| 1 | M1・M2 | 1,500 | 20 | 怪獣研究 |
| 2 | M3・M4 | 4,500 | 30 | 怪獣強化 |
| 3 | M5・M6 | 12,000 | 40 | 怪獣改良 |
| 4 | M7・M8 | 30,000 | 60 | 究極の怪獣 |

### 生物の技術（4個）
| 技術 | 必要ポイント | 前提 | 効果 |
|---|---|---|---|
| 怪獣研究 | 800 | なし | 怪獣研究所を建て、段階1の怪獣を育てられる |
| 怪獣強化 | 1,500 | 怪獣研究 | 段階2の怪獣を育てられる |
| 怪獣改良 | 2,500 | 怪獣強化 | 段階3の怪獣を育てられる |
| 究極の怪獣 | 4,000 | 怪獣改良 | 段階4の怪獣を育てられる |

### 防壁
- **防壁建設**（費用300、平地）：怪獣が入れないマス。ミサイルが当たると壊れる。電力は使わない。

### 怪獣使い型の AI
- M3 のバランス型を怪獣使い型にする。生物の研究を優先し、怪獣研究所を建てて怪獣を育て、スコアの最も高い島か、最近攻撃してきた島に送る。
- どの AI も、自分の島に怪獣が出たら、ミサイル基地があればその怪獣を撃つ。

### 災害
- 新しいゲームを始めるときに**災害の強さ**を「なし／弱い／ふつう」から選ぶ（補正 0／0.5／1）。野生の怪獣の出やすさにも効く。
- 毎ターン、島ごとに次の確率（「ふつう」のとき）で起きる。

| 災害 | 確率 | 効果 |
|---|---|---|
| 地震 | 0.5% | 都市（人口1万人以上）・工場・発電所・研究所が、それぞれ1/8の確率で荒地になる |
| 津波 | 0.5% | 海に面した住宅地・農場・工場・施設が、「面している海のマス数−1」/12 の確率で荒地になる |
| 台風 | 0.5% | 農場が、それぞれ1/4の確率で平地になる |
| 隕石 | 0.5% | ランダムなマスが深い海になる。1/2の確率で続けて落ちる |
| 巨大隕石 | 0.2% | ランダムなマスを中心に、中心は深い海、周囲1マスの陸地は浅瀬、周囲2マスは荒地になる |
| 噴火 | 0.5% | ランダムなマスが山になり、周囲1マスの陸地と浅瀬は荒地、深い海は浅瀬になる |

- 災害に巻き込まれた怪獣は倒れる（死骸の値段は入らない）。
- ログには自分の島の災害だけを出す。

### 画面
- 怪獣のマスを選ぶと、種類・体力・能力を表示する。他の島の怪獣も見える。
- 自分の島の怪獣のマスを選ぶと、命令メニューにミサイルの命令が出る。
- 怪獣研究所のマスを選ぶと、育てている怪獣と残りターン数、育ち上がった怪獣が見える。
- AI の島を表示しているときの命令メニューに「怪獣派遣」を出す。

### セーブ
- セーブデータの形式を版4にする。版3のセーブデータは、災害の強さを「ふつう」として読み込む。

### 実装で決めた細かい点
- **序盤の保護（最初の100ターン）の間は、災害も野生の怪獣も起きない**。何もしないでいると、地震で都市が壊れて
  人口0になり、40ターンほどで滅亡することがあったため（操作を覚える前に負けないように）。
- 噴火：周囲1マスの深い海・油田・海底基地は浅瀬に、浅瀬と陸地は荒地になる（原作と同じく浅瀬は荒地になる）。
- 津波：島の端のマスは、島の外も海として数える。
- 怪獣の移動先は、島の中の隣のマスから選ぶ（島の外は選ばない）。
- 範囲破壊は、海・山・怪獣・荒地以外の周囲のマスを荒地にする。
- 怪獣派遣は、予約を実行するときに育ち上がった怪獣がいれば送る（いなければ実行せず、ターンも消費しない）。
- 自分の島へのミサイルは、ばらつきで自分の施設に当たることがある。AI はばらつきの小さい弾から使う。
- AI の調整：工場を研究所や軍備より先に建てる。資金が60億円以下のときは整地をしない
  （資金が尽きて農場を作れず、飢えて滅亡することがあったため）。
- 試しに AI だけで800ターン進めると、怪獣使い型は800ターンで約40回怪獣を送り込んだ。
  怪獣の影響は大きく、送り込まれた島が滅亡することもある（強さは M5 のバランス調整で見直す）。

## 20. M5：ドット絵とバランス調整

### ドット絵
- すべてのマスと怪獣8種を、16×16のドット絵で描き直した（`src/ui/sprites.ts`）。マスには2倍に拡大して描く。
- 絵は1文字1ドットの文字列で書き、色は1か所の色表にまとめる。森・家・建物などの部品を地面の絵に重ねて作る。
- 怪獣は段階ごとの形（段階が上がるほど大きく、角が増える）に、種類ごとの色を塗る。
- 発電所・研究所・基地の段階と、怪獣の体力は、絵の上に小さな印で重ねて描く。

### バランス調整の目標
- 1回のゲームは、1,000〜1,500ターンで決着する（5秒間隔で約1.5〜2時間）。
- AI は手強く、プレイヤーが何もしなければ AI が先に制覇する。

### 調整のしかた
- `npm run sim` で AI 同士の自動対戦を回す（`src/engine/simulate.ts`・`balance.sim.ts`）。プレイヤーの島は何もしない。
  プレイヤーの勝敗では止めず、AI のどれかが制覇するか、期限が来るまで進める。対戦数は `SIM_GAMES` で変えられる。

### 変えた数値と理由
| 項目 | 前 | 後 | 理由 |
|---|---|---|---|
| 経済的制覇の目標人口 | 100万・150万・200万（標準150万） | 60万・80万・120万（標準80万） | 20×20の島では人口が100万人前後で頭打ちになり、経済的制覇が起きなかった |
| 怪獣を育てる費用・ターン数 | 1,000〜20,000・10〜30 | 1,500〜30,000・20〜60 | 怪獣使い型がほとんど毎回勝っていた |
| 増殖の確率 | 50% | 30% | 同上 |
| 野生の怪獣が出始める人口 | 20万・40万・60万・80万 | 30万・50万・70万・90万 | 怪獣で人口が伸びなかった |
| 地震で都市・施設が壊れる確率 | 1/4 | 1/8 | 災害で人口が伸びなかった |
| 怪獣使い型の怪獣研究所 | 2棟 | 1棟 | 怪獣使い型が強すぎた |

### AI の変更
- 自分の島に怪獣がいて基地がなければ、まずミサイル基地を建てる（内政型は500ターン目まで基地がなく、怪獣を撃てなかった）。
- 内政型は「精密誘導」を早めに研究する（通常弾で自分の島の怪獣を撃つと、自分の町まで壊すため）。
- **どの AI も、経済的制覇の目標人口の60%を超えた島のうち、いちばん人口の多い島を優先して攻撃する**（ミサイルも怪獣も）。
  先行する島の独走を止めるため。プレイヤーが先行したときも狙われる。

### 結果（20回の対戦）
- 決着までのターン数：中央値1,111（567〜2,000）。
- 決着のしかた：経済的制覇14回・軍事的制覇5回・期限1回。
- 勝った AI：怪獣使い型14回・内政型6回・軍事型0回。

### 残っている課題
- 軍事型の AI が一度も勝っていない。先行する島を叩く役回りにはなっているが、軍事的制覇（他の3島をすべて滅亡させる）は難しい。
- 怪獣使い型がまだやや強い。
- プレイヤーが実際に遊んだときの手応えは、遊びながら確かめる必要がある（自動対戦ではプレイヤーは何もしない）。

## 21. 観戦モード

AI だけの戦いを、速い間隔で眺めるモード。

- ヘッダーの「観戦モード」から始める。設定画面で、経済的制覇の目標人口・期限・災害の強さを選ぶ（通常のゲームと同じ）。
- **島は4つで、すべて AI**。プレイヤーの島の場所にも AI を置く（名前は「西の島」、性格は3種類から乱数で選ぶので、1つは重なる）。
- **ターンの間隔は 0.1・0.25・0.5・1・2秒**から選び、途中でも変えられる（初期値0.25秒）。0.1秒なら1分で600ターン進む。
  選んだ間隔は、通常のゲームの間隔とは別に覚えておく。
- 命令の予約やミサイルのメニューは出さない。マスを選ぶと、その情報だけを出す。
  観戦中は、ミサイル基地や海底基地も隠さずに見せる。研究の画面は出さない。
- ログには、すべての島の攻撃・災害・怪獣・食料不足・滅亡を、島の名前付きで出す。
- 決着は通常のゲームと同じ3つの勝ち方で判定し、勝った島を表示する（プレイヤーの勝ち負けはない）。
  西の島が滅亡しても、観戦は続く。決着したら「もう一度観戦」「観戦をやめる」「島を眺める」を選べる。
- **観戦中は自動セーブしない**。遊んでいたゲームの自動セーブはそのまま残り、「観戦をやめる」でそのゲームに戻る。
  （自動セーブがなければ、新しいゲームの設定画面になる。）
- 観戦中は、新しいゲーム・セーブの書き出し・読み込みのボタンは出さない。

## 22. 平和モード

戦わずに島の開発を楽しむモード。新しいゲーム（観戦も）の設定画面で選ぶ。

- **他の島を攻撃できない**。他の島へのミサイルと怪獣の派遣は実行できない（予約もできない）。
  自分の島の怪獣をミサイルで撃つことはできる。
- **AI の島はいるが、攻撃しない**。怪獣使い型も怪獣研究所を建てず、怪獣を送らない。開発と研究で人口やスコアを競う。
- **野生の怪獣と災害は、設定（災害の強さ）のとおりに起こる**。
- **勝利条件を満たしてもゲームは終わらない**。満たしたことは1回だけログと通知で知らせる。
  - 経済的制覇の目標人口に届いた（自分の島も AI の島も）
  - 他の島がすべて滅亡し、1島だけが残った
  - 期限のターンを迎えた（そのときのスコア1位を知らせる）
- **自分の島が滅亡したら終わる**（負け）。観戦モードで平和モードを選んだときは、終わらない。
- 画面：ヘッダーに「平和モード」の印を出す。他の島を表示したときは、攻撃のメニューの代わりに島の情報を出す。
- セーブデータ：設定に「平和モード」の項目を足した（ない古いセーブデータは平和モードでないものとして読む）。版は変えない。

## 23. 初期の島を原作と同じ狭さにする

- 初期の島を、原作（箱庭諸島２）と同じ作り方にした。マップは20×20マスのままで、島は中央だけを使う。
  1. 中央の4×4マスを荒地にする。
  2. 中央の8×8マスの範囲から120回マスを選び、そのマスか隣に陸地があれば「深い海→浅瀬→荒地→平地」と1段階ずつ陸地にする。
  3. 中央の4×4マスに森4・村2・山1を置き、農場1を加える（原作のミサイル基地は置かない）。
- 陸地はおよそ25〜40マス（平均31マス）。以前は100〜150マスだった。島を広げるには埋め立てが要る。
- **序盤の保護（最初の100ターン）の間は、食料不足による暴動が起きない**。狭い島では村がすぐに増えて食料が足りなくなり、
  たった1つの農場が暴動で壊れて、何もしないと35ターンほどで滅亡していたため。食料不足で人口が減ることは保護の間も起きる。
- **AI の変更**（狭い島で行き詰まらないように）
  - 平地がなく、食料や働き口が足りなければ、人口のいちばん少ない村を農場や工場にする。
  - 平地と荒地が合わせて4マスより少なくなったら、埋め立てで島を広げる。資金に余裕があるときも埋め立てる。
  - 研究所が1つもなければ、工場の次に優先して建てる。
- **経済的制覇の目標人口**を、30万・45万・60万人（標準45万人）にした。狭い島では AI の人口が30万〜50万人ほどで頭打ちになるため。
- 自動対戦の結果（20回）：決着の中央値1,294ターン（517〜2,000）。経済的制覇7回・軍事的制覇8回・期限5回。
  勝った AI：怪獣使い型12回・軍事型5回・内政型3回。

## 24. 人工衛星（仮の数値）

- 衛星は4種類。各島に種類ごとに1つまで持てる。

| 衛星 | 打ち上げ費用 | 成功率 | 必要な研究 | 効果 |
| --- | --- | --- | --- | --- |
| 気象衛星 | 3,000億円 | 80% | 宇宙開発 | 台風が起きる確率が1/5になる |
| 観測衛星 | 5,000億円 | 70% | 観測衛星 | 地震・津波・噴火の確率が半分になる。他の島のミサイル基地と海底基地が見える |

- **耐久**：打ち上げると100。毎ターン1ずつ減り、0になると失われる。
- **修復**（人工衛星修復）：打ち上げ費用の半分で、耐久が150に戻る。1ターンを使う命令。
- **衛星レーザー**：2,000億円。他の島（自分の島も可）の狙ったマスを確実に壊す。迎撃されない。軍事衛星の耐久が10減る。
  怪獣に当たると体力が1減る（硬くなっている間は効かない）。海・荒地・山に当たっても効果はない。
  序盤の保護の間と平和モードでは、他の島には撃てない。
- **研究**：新しい系統「宇宙」。宇宙開発（1,000）→観測衛星（1,500）→迎撃衛星（2,500）→軍事衛星（4,000）。打ち上げ改良（1,200、前提は宇宙開発）。
- **AI**：性格に合った衛星を、資金が打ち上げ費用＋5,000億円を超えたら打ち上げ、耐久が25を切ったら修復する。

  - 怪獣使い型：気象だけ。
